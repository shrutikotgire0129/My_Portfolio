# Shruti Kotgire — Personal Portfolio

A personal developer portfolio built to showcase my projects, technical skills, and journey as a Software Engineer and Full-Stack Developer.

The portfolio features a clean, responsive design with a dark forest-green theme, elegant gold accents, and dedicated sections for my background, projects, and contact information.

## Live Demo

**Portfolio:** [View Live Portfolio](https://my-portfolio-six-ruby.vercel.app/)

## Features

- **Home:** Introduction and overview of my development profile.
- **About:** Background, technical skills, and resume.
- **Projects:** Selected projects with descriptions, technologies, and demo links.
- **Contact:** Ways to connect with me professionally.
- **Responsive Design:** Layout optimized for desktop, tablet, and mobile devices.
- **Custom Favicon:** Personalized site icon.
- **Dark Visual Theme:** Forest-green backgrounds with gold accents and refined typography.

## Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/shrutikotgire0129/My_Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd My_Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

To verify the production build:

```bash
npm run build
```
